## 🚀 Featured Projects

### 🔹 Agentic RAG Platform — Conversation-Centric Document Q&A
Full-stack Agentic RAG platform enabling document upload and LLM-grounded, multi-turn Q&A via a hybrid retrieval layer (vector similarity + keyword search + metadata filtering).
**Stack:** Python, FastAPI, React.js, PostgreSQL, pgvector, LangChain, LLM APIs

### 🔹 Databricks Genie Space Automation & Provisioning
Automation platform that provisions a Databricks Genie Space from requirements, generates evaluation test cases, and runs an agent that iteratively fixes failing tests until they pass — then provisions a Databricks App as the chat UI.
**Stack:** Python, FastAPI, Databricks SQL, Unity Catalog, Delta Lake, LangChain, LangGraph
